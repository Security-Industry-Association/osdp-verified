## Test 050-06-01 Packet Size Limits ACU to PD ##

The implementation of the standard message set requires all devices to
be able to accept packets up to 128 bytes long and be able to tolerate
messages addressed to other devices having a total length not exceeding
1440 bytes.

If the packet was meant for another device, there should be no adverse
condition created in the PD with the limitation i.e. the PD should not fail 
if it receives a well-formed properly addressed packet larger than it can process.
The PD is expected to either drop the packet or respond with a NAK.
An ACU which sends an oversize packet is responsible for recovering if the
PD drops it.  It is not an error for the PD to drop the packet.

### PD ###

PD MUST use multi-byte data encoding when necessary for message
processing.

### ACU ###

ACU MUST use multi-byte data encoding when necessary for message
processing.

### Purpose ###

Confirm PD can tolerate a command of any legitimate size.
